# IJCAS 분석 결과 정리 (AI 입력용)

작성 2026-11-13. 모든 수치는 `analysis/results/*.json`에서 나온 측정값이다. 추정·가설은 [가설]로 표시한다.
학습 없음. 3개 학습 planner(동결)의 출력 덤프에 대한 CPU 후처리 분석이다.

## 0. 설정
- 데이터: ETRI E2E Driving Dataset, 376 scene(10 Hz, 카메라 6대), scene 단위 분할 학습 301 / 검증 75.
- 평가 창: 검증 scene에서 5프레임 간격, 4045창 중 이동 command 3777창(LK 3321, LCL 138, LCR 58, TL 142, TR 118). mode planner는 3774창.
- planner 3개: `cell105`(105-cell), `cell15`(15-cell), `nocell`(mode planner). 같은 구조, 다른 궤적 head.
- 계획 Ŷ: 6 waypoint, 0.5 s 간격(3 s). 오차 지표 E_plan = 1·2·3 s까지의 평균 변위오차의 평균(m). 신뢰구간은 75 scene bootstrap 2000회.
- 투영: 운동학 모델 (x, y, ψ, v), 입력 (a, κ). 상자 𝒰 = a∈[−1.99, 1.85] m/s², |κ|≤0.113 1/m(학습 scene 실제 주행의 99.9 백분위, 물리 한계 아님).
  - 비용 = ‖P(u;v₀,ψ₀) − Ŷ‖² + ρ_a²‖Δa‖² + ρ_κ²‖Δκ‖² + 연성 벌점(횡가속 2.51, jerk 2.38).
  - **rollout 초기조건은 v₀, ψ₀(속도벡터 방향)뿐이다.** a₀, ω₀(κ₀=ω₀/v₀)는 첫 rate 항 Δa₁=a₁−a₀, Δκ₁=κ₁−κ₀의 기준값으로만 들어간다.
  - 상태 출처: `meas` = 기록된 차량 운동 데이터(실측), `est`/`obs` = 네트워크 내부 추정.
  - solver: projected Levenberg–Marquardt, numba, 창당 0.1 ms.
- 가중치 선택: 검증 scene 안 scene 단위 5-fold CV(평가 fold는 선택에 미사용). 실측 상태에서 5개 fold 모두 같은 값:
  cell105·cell15 (ρ_a, ρ_κ)=(5, 5), nocell (10, 5).
- 주의: 검증 scene을 설계 과정에서 여러 번 봤으므로 완전히 독립된 테스트 세트라고 주장하지 않는다.

### 1.6 투영 정리 확인 (정규화 없는 투영 ρ=0, 실측 상태)
이득 항등식(항상 성립): ‖P−Y‖² − ‖Q−Y‖² = ‖P−Q‖² + 2(P−Q)ᵀ(Q−Y).
정확한 볼록 투영이고 Y∈ℛ이면 정렬 항 ≥ 0, 즉 제곱 이득 ≥ ‖P−Q‖².
| | cell105 | cell15 |
|---|---|---|
| E: 보정 없음 → ρ=0 투영 | 0.279 → 0.260 | 0.286 → 0.275 |
| 제곱 이득 ≥ 보정량² 비율(전체) | 62% | 63% |
| 같은 비율, 실제 궤적이 ℛ 안(d_gt<0.05 m, 3360창) | 66% | 66% |
| 삼각 부등식 ‖Q−Y‖ ≤ ‖P−Y‖ + d_gt 성립 | 99.6% | 99.0% |
- d_gt = 실제 궤적을 같은 solver(ρ=0)로 투영했을 때의 이동량. 도달 가능 집합까지의 정확한 최단거리가 아니라 경험적 대용값이다(국소해). 중앙값 0.005 m.
- **볼록 투영 성질은 1/3 창에서 깨진다**(비볼록 집합·국소해). 손해 비율은 d_gt와 함께 증가: d_gt<0.05에서 21%, 0.05–0.2에서 52%, 0.2–0.5에서 71%, ≥1에서 82%(cell105).

## 2. 제어기 포함 평가 (closed loop, 비반응 재생)
- 평가 plant는 투영 모델과 다르게 설정: 동역학 single-track, 선형 타이어 μ=0.9 포화, 3–5 m/s에서 운동학 모델과 혼합, 지연 τ_a 0.3 s / τ_δ 0.1 s, a∈[−6, 3], 조향속도 0.6 rad/s.
- 제어기 50 Hz, feedforward + feedback. 게인은 실제 주행 궤적 600창에서만 조정(계획 미사용). 공통 cubic spline 기준.
| cell105 | 실행 오차 | 추종 RMS | jerk RMS | 포화 비율 |

| 학습 계획 | 0.227 (계획 자체 0.279) | 0.086 | 0.48 | 1.8% |
